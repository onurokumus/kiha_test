# Propeller Test Tool logo

Generated with the built-in ImageGen tool, then downscaled with Lanczos and encoded as WebP using Pillow. The artwork was generated and its background corrected by ImageGen; conversion only resizes and compresses the result.

- App asset: `frontend/public/ptt-logo.webp`
- Header display: 32 × 32 CSS pixels; asset: 64 × 64 pixels for sharp 2× displays.
- Encoding: WebP, quality 82, method 6, no source metadata.
- The header and favicon share this one asset; both respect Vite's configured base path.
- Opaque charcoal background matches the header. The first generation's checkerboard was replaced with ImageGen before encoding.

## Generation prompt

Use case: logo-brand. Asset type: a small application header logo for Propeller Test Tool, a scientific workbench for propeller and electric motor test-rig data. Create ONE distinctive, professionally designed, standalone emblem: a clean three-blade aircraft propeller seen straight on, with swept aerodynamic blades arranged symmetrically around a small round hub, integrated into a simple open circular measurement ring. It must read clearly as a propeller at just 32 pixels. Flat, precise, vector-like shapes with smooth crisp edges and generous negative space; blue steel and pale ice blue (#8bbdde and #c6e8fa), restrained darker blue for depth. Designed to stand out on the app's charcoal #252526 header. Square composition, emblem centered and occupying about 88% of the canvas. Genuinely transparent background and transparent negative space, preserved alpha. No text, no letters, no wordmark, no slogans, no gradients, no shadows, no glow, no mockup, no extra symbols, no checkerboard drawn into the artwork. Output a single polished logo asset.

## Final background correction prompt

Use case: precise-object-edit. Edit the supplied propeller logo asset. Keep exactly the same three-blade propeller silhouette, blue and ice-blue palette, circular broken measurement ring, centered square composition, and relative size. Change ONLY the background: completely remove the entire grey checkerboard and all background patterns and replace every background region, including the spaces between blades and inside the ring, with one perfectly uniform solid charcoal color #252526 (RGB 37, 37, 38). The backdrop must be entirely flat and seamless, no texture, no gradients, no shadows, no transparency checkerboard. This logo will be used as a tiny 32-pixel header mark on a #252526 web app header. Preserve clean anti-aliased boundaries against that exact charcoal. No text or extra elements.
